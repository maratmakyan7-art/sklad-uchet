# Склад Учета — Система управления запасами

Веб-приложение для учёта сельскохозяйственного склада.

## Возможности (уже работают)

- Справочник товаров с фото
- Справочник машин / механизмов
- Поиск по товарам
- Добавление и редактирование товаров

## Что будет дальше

- Приход товара (по накладной + цены и НДС)
- Расход товара (на машину / место)
- Остатки на складе
- История движений
- Отчёты

## Как запустить

1. Установите Python 3.9+ (если ещё нет)

2. Откройте терминал в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

3. Запустите программу:

```bash
streamlit run app.py
```

4. Чтобы заходить с других устройств в той же сети (телефон, другой компьютер):

```bash
streamlit run app.py --server.address 0.0.0.0
```

После запуска откройте в браузере адрес, который покажет Streamlit (обычно http://localhost:8501).

## Структура папок

- `app.py` — основная программа
- `database.py` — работа с базой данных
- `sklad.db` — база данных (создаётся автоматически)
- `images/` — папка с фотографиями товаров
